Wire log

    The real one

    GonzalezDesk replaced paid remote-access licenses for a multi-office practice. A Windows client runs on 20 machines, and one relay server routes every session. These are the numbers measured at 1920×1080 before and after the v2 rewrite.

    Host CPU per frame
    18.3 ms → 2.64 ms
    Data per frame
    42.3 KB → 4.2 KB
    Four live sessions
    ~55 Mbps → ~5.6 Mbps
    Picture sent
    960 px Q30 → 1920 px Q65

    Same as the real app

    • Tile-delta codec: only changed tiles are JPEG-encoded. A full keyframe goes out every 5 s, or whenever more than 60% of the screen changed.
    • Wire format: the same 12-byte header (magic, version, kind, flags, source, destination, sequence, length) and the same tile record layout.
    • Input lane: mouse moves are merged down to the latest position, but clicks and keys are never dropped. The cursor travels as its own tiny packet.

    Simulated here

    • The network: packets are handed across with a fixed 35 ms delay in place of a real relay server.
    • Sign-in: the real owner device proves who it is with an Ed25519 key signature, so ID 0 needs no password and can't be impersonated. Here that exchange is only logged.
    • Screen capture: the real client grabs the Windows desktop through DXGI. Here the "remote desktop" is drawn on a canvas at half size.
